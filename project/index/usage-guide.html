圆几何学习平台使用说明

这是一份面向普通用户的快速指南。你可以按下面的推荐流程，从“看知识点”到“做题巩固”逐步学习。

推荐学习路径：主页 → 知识点图示 → 测试中心 → 每日一题
返回主页 进入测试中心 进入游戏中心

1. 主页能做什么

  • 顶部可以切换语言（中文 / English）。
  • 设置菜单可以切换主题（默认 / 护眼 / 夜晚）。
  • 字体大小滑块可以全站统一调节字号，方便不同视力需求。
  • 中部轮播图可进入 4 个知识点可视化页面（动态演示定理关系）。
  • AI 问答框可输入圆几何问题，快速获得解释。

2. 知识点图示页面怎么用

  • 通过主页轮播图点击进入 `indexPicture01/02/03/05.html`。
  • 页面包含拖拽点、角度滑块、图形标注等交互元素，可直观看到定理变化过程。
  • 适合先理解概念，再进入练习题巩固。

3. 测试中心模块说明

  • `home.html`：测试首页（模块入口）。
  • `test-topic.html`：专题练习，按知识点专项训练。
  • `test-comprehensive.html`：综合练习，混合题目检测整体掌握情况。
  • `daily.html`：每日一题，保持学习节奏。
  • `quiz.html`：答题主页面，含 AI 解析与错题记录逻辑。
  • `test-prep.html`：使用教程与流程说明页。

4. 游戏中心模块说明

  • `game.html`：游戏中心入口。
  • `game first version final.html`：圆心角与圆周角配对游戏。
  • `game second version final.html`：直线与圆位置关系判断。
  • `game third version final.html`：弧长与角度关系挑战。
  • 每个游戏都支持计时、评分，适合查漏补缺。

5. 建议的学习顺序

  • 先看知识点图示，理解“图形变化与定理关系”。
  • 进入专题练习做针对性训练。
  • 再做综合练习，检验迁移能力。
  • 每天完成每日一题，保持稳定进步。
  • 最后用游戏中心做轻量复习，提升学习兴趣。

6. 常见问题

  • 页面字体太小：请回到主页右上角设置里调大字体。
  • 夜间看得累：切换夜晚模式或护眼模式。
  • 内容显示为英文：在右上角切回“简体中文”。

提示：平台的语言、主题、字号会自动保存，下次打开仍然生效。
